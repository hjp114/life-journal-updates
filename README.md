# 人生手记安装包与更新

安卓个人记录应用，支持 Android 10 及以上。

当前版本：0.1.7。 [下载最新版](https://github.com/hjp114/life-journal-updates/releases/tag/v0.1.7)

本仓库用于发布 APK、版本信息和更新说明，不包含个人日记、照片、账目、登录凭据或签名私钥。

首次安装从 Releases 下载 APK；后续在 App 的“设置 → 应用更新”中更新。签名一致的新版采用覆盖安装，安装前由应用保存最近一次本地恢复副本。请勿先卸载应用。

这是测试版本，实际手机兼容性与账号登录仍需验证。

## 本版变化

0.1.7 修复版：加强 ChatGPT 浏览器授权回调，新增本机备用完成入口和独立刷新模型。

修复单个浏览器空闲或不完整连接会结束整次登录的问题。读取完整且有大小限制的回调请求，先向浏览器确认已收到授权，再在原生层交换和核验凭据，失败阶段在 App 中说明。

授权期间使用有时限、可取消的登录通知。等待状态在手机加密保存，Activity 重建可接回原来的连接，进程重建后在有效期内恢复等待；凭据交换中断则提示重新连接。

增加“浏览器无法返回？完成授权”本机备用入口，只接受本次有效的回调，拒绝地址不符、状态不符、重复提交、取消后或过期的返回。保留 PKCE、OIDC 签名与账户校验。输入不进入日记、聊天、备份或 AI 请求，提交、取消和关闭后清空。

验证身份后保存授权；模型列表失败不再丢弃已验证凭据，可以独立刷新模型。重新连接失败保留原有连接，个人记录与 API 配置不受影响。

原生回调和授权逻辑用真实本地套接字及模拟 HTTPS/JWT 验证，网页流程用模拟原生桥接验证；没有进行真实账户、实际手机前台服务或浏览器验收。尚不能断定用户手机的具体触发原因，覆盖安装后需实机确认。

## 使用说明

### 随手记一件事

在记录页写个大概，点击发送就保存。默认一行输入框，内容增加时长高，最多约四行；更长的文字在框内滚动。记录和 AI 页面使用同样的输入方式，键盘弹出时只调整内容和输入区，底部导航留在原来的屏幕底部，被键盘遮住。

“＋”里有图片、快速记账和右侧清空。清空需确认，只清除当前未发送草稿。点记录正文看全文，点卡片“⋯”进行编辑、分类关联、AI 分析、关联支出、导出或删除。

### 深入复盘

点击记录卡片的“深入复盘”。六项标题都能看到，默认收起，点某项展开：事情经过、想法与感受、我的行动、实际结果、经验与发现、下一步。全部选填，写一项也能保存。事情经过可以引用原记录，不必重复输入。

逐题引导在复盘页内，需要时开启；它与自由填写共用内容，可跳过、返回或直接选题。返回、切换和退出均保留复盘草稿，卡片显示“继续复盘 · 有草稿”。点击保存才更新同一条正式记录，原文保持完整。完整备份包含未确认的复盘草稿，AI 分析只用正式保存的内容。

### 分类与关联、编辑

卡片“⋯ → 分类与关联”或复盘页底部，选择多个主题、阶段目标和实际执行行动。所选目标下的行动优先显示，仍能选择其他行动。关联行动不自动完成行动；可以记录过程、问题或结果。卡片上的关联摘要也可直接点击修改。

“编辑记录”修改原文、图片和日期。编辑与复盘共用同一条正式记录，但复盘使用独立草稿，不占用下一条随手记草稿。编辑原文时若已有未发送的普通草稿，界面先询问是否替换。

### 日历和补记

日期格用圆点表示记录、空心点表示计划、小铃铛表示具体事项提醒。点日期查看当天摘要，记录优先，其次提醒、计划与行动，账目折叠。点今天可回到当前日期。每日记录、每周回顾等通用提醒在当天的折叠区，不让整个月都出现铃铛。

日历不再提供重复的“记录这一天”按钮。选中日期后点底部记录，自动带上该日期，输入区显示“补记”。已有未发送草稿保留原日期并提示；空白输入区可点回到今天。日期切换本身只改变查看日期，保存记录使用草稿显示的日期。

### 具体事项提醒

在日历点添加提醒，填写事项、日期、时间。默认仅一次；重复与关联选填，可设每天、每周、每月以及关联目标或行动。每月的日期不存在时安排在当月最后一天。

每次只通知一次，未处理的保留在日历。勾选完成只完成这次提醒，不完成关联行动；后续重复周期照常。可以手动稍后提醒、修改或取消整个事项。修改时间或重复方式不会抹掉已有完成日期。取消提醒不删除关联规划或记录。

已过去的一次性提醒不会自动补发通知，显示待处理，可设置稍后提醒。通知依赖手机权限及系统闹钟调度，省电或强制停止 App 可能使其延迟或停止；打开 App 或重启手机会重新安排未来提醒。点击通知进入对应日期。实际到点通知和键盘表现仍需手机验证。

### AI 对话

发送后问题保存在对话中，生成时发送按钮原位变为停止；停止保留已有回复。输入框上方只在有参考记录或图片时显示数量。上翻读旧回复时保留位置，点回到最新再跟随回复。

“＋”：图片、参考记录、右侧清空。参考记录面板可以预览发送内容。顶部模型名称：切换模型、管理连接、查看调用额度说明。顶部“⋯”：导出分析、导入结果、自我认识、观点与表达练习、收藏。设置：长期记忆、上下文压缩、发送偏好。

AI 调用仅在主动发送、压缩或提炼时发生，使用当前连接的服务与额度。先检查发送预览，核对背景、规划、参考记录、图片、记忆与历史对话是否符合你的意图。模型的建议由你确认，不能自动当作个人事实。

### 分享、迁移和更新

QQ 分享 APK 只分享软件，不带日记、照片、账目、对话或 API 密钥。完整备份 ZIP 和分析导出可能包含私人资料及图片。换手机要导出完整备份，在新手机安装 App 后恢复；新手机的 AI 连接需要重新设置。

更新使用同一签名覆盖安装，不先卸载。卸载会删除应用数据。0.1.7 安装包见 [GitHub Releases](https://github.com/hjp114/life-journal-updates/releases/tag/v0.1.7)，也可在 App 的“设置 → 应用更新”中检查新版。


### 记忆增强

设置 → 长期记忆库。常用入口是集中核对、人物与事件；新增、提炼、纠正和设置在“整理与纠正”中。

- **集中核对**：阅读提议和原文依据，勾选确认。只确认所选条目；推测不能批量确认。记忆可标注明确事实、当时感受、待验证推测、方法与反馈、计划、具体经历，以及日期、人物和事情。时间未标注的旧记忆保持兼容，不自动当成当前状态。
- **人物与事件**：输入名称查看按日期排列的经历。可为人物、事情或主题添加名称与别名；按名称、别名及相关词找回早期和近期、不同结果的记录及原话。检索不保证找全，列表过长时缩小查询范围。
- **整理新增资料**：把新增或修改的正式日记、用户聊天原文交给当前模型整理，先形成待确认提议；不会上传未保存复盘草稿，也不会把 AI 建议自动当作你的事实。提议关联原文，重复提议按内容、类型和日期去重。没有重要内容时也可标为已整理；源文修改后重新进入待整理。
- **自动整理**：默认关闭，可在记忆增强设置中开启。App 打开、允许发送背景且连接可用时，在成功回复之后、至少4条新增资料时，每24小时至多自动一批。使用模型额度；可停止。每批按容量选择最多40条来源，未处理内容仍保留。单条过长时需分段整理，失败不会删除原文或推进已整理进度；手动整理不受每天一次限制。
- **纠正旧认识**：填写不准确之处和现在的情况，可选择暂停使用的旧记忆。相关问题会附带纠正，旧经历保留。删除纠正不会自动恢复旧记忆，仍需核对。
- **阶段摘要与原文**：压缩时请求模型同时给出累计摘要和本批独立阶段摘要，独立摘要保留具体消息来源，可检索并回查。摘要可能遗漏细节；模型仅返回累计摘要时仍可正常压缩，原文继续保留。
- **本次依据**：AI 回复下可查看此次使用的记忆、经历、相关旧对话、规划行动数量、账目范围和遗漏提示，并进入原文或纠正入口。它是发送时的来源清单，之后修改的原文会标记或暂停用于后续对话。

记忆增强设置可单独关闭人物事件检索、规划行动和账目读取。已确认的基础背景及表达偏好持续提供；其他记忆按问题匹配。时间线遵循长期记忆和跨对话开关；关闭“附带个人背景”后停止所有增强资料，当前对话及主动选择的参考记录仍提供。

账目仅在消费、收入、预算等相关问题中附带，默认本月截至今天；支持今天、最近一周、上月、全部或明确日期范围，例如“2026-10-01 到 2026-10-10 的消费”。金额以分保存，100分等于1元。合计覆盖范围内全部已记录账目，明细可能因容量未全部发送，预览会显示范围、笔数及遗漏数。未记录的收支无法分析。

完整备份包含人物别名、纠正、待确认提议、整理进度和阶段摘要。分析导出在包含背景时附带纠正与人物名称，仍需注意私人信息。新开对话无需重复已确认的背景，但不能保证找回每个细节或完全避免误判。


### ChatGPT 登录后本地页面无法访问

点击 Continue with ChatGPT 跳转系统浏览器是正常流程。授权时 App 会使用一个短时登录通知，减少切换到浏览器后回调被暂停的机会；完成、取消或超时后停止。通知权限被关闭时，系统对服务的显示方式可能不同。该服务只用于本次登录，不运行 AI 分析。

如果同意授权后，127.0.0.1 页面仍显示拒绝连接或无法访问：

1. 回到人生手记的设置 → AI 连接，查看登录状态。若已显示已连接，直接刷新模型或测试文字连接，不必再次授权。
2. 如果仍在等待，点击“浏览器无法返回？完成授权”。复制这次错误页地址栏的完整返回地址，只粘贴到 App 的这个输入框中，然后确认。
3. 等待状态8分钟内有效，地址仅适用于同一次登录。重新开始登录后旧地址失效；超时或授权处理中断后，需要重新连接。已有连接与个人记录保留。
4. 已授权但模型列表读取失败时，点击刷新模型即可，不必反复重新授权。

返回地址包含一次性授权信息，不要发到聊天、日记或其他软件。备用输入框内容不会写入日记、对话、备份或交给 AI；提交、取消和关闭后清空。App 检查回调地址、随机状态、PKCE、身份签名和当前连接归属，不降低授权校验。

本地等待信息使用手机密钥加密保存，不进入备份或换机迁移。系统进程回收后可在有效期内恢复等待；若是在交换凭据时被系统中断，需要重新连接，旧连接不被覆盖。手机浏览器、网络代理和系统省电策略仍可能影响自动返回，需要实际手机验证。
